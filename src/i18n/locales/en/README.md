# Локаль `en`

Английская локаль — зеркало раскладки локали `ru`: те же доменные файлы
и группы ключей. Карта структуры и правила правок — `../ru/README.md`.

- Источник перевода — файлы `../ru/**` (переводится только значение; ключи,
  порядок и вложенность — как в ru-источнике).
- Канон игровых терминов — официальные английские строки
  `export/core_db/Lang/english/texts/*.json`.
- Канон концептов редактора — глоссарий мануала: `docs/manual/ru/20-glossary.md`
  (зеркало — `docs/manual/en/20-glossary.md`).
- Плюралы: ru-группа `_one/_few/_many` → en-пара `_one/_other`
  (правила i18next для английского; суффиксов `_few`/`_many` в en не бывает).

Подключение локали к i18next (`resources.ts`, `SUPPORTED_LOCALES` в
`src/i18n/index.ts`) — зона ответственности кода, файлы локали её не касаются.
